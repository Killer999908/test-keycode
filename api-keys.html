Frequently Asked Questions

API keys allow you to programmatically access KEYCODE services. Use them for CI/CD pipelines, custom integrations, automation scripts, and third-party tool connections. Each key grants access based on its permission level.

Read Only — View projects, stats, and account info. Read & Write — Create and modify projects and resources. Full Access — All operations including billing and admin actions. Always use the least permissive level needed.
