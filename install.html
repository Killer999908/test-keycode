Browser app

Install KEYCODE Studio

Add the website to your device as an app. Supported browsers open a native install prompt; on iPhone and iPad, follow the Safari home-screen steps.

  • Android, Windows, macOS, Linux, and ChromeOS: use the install button or your browser menu.
  • iPhone and iPad: open this page in Safari, tap Share, then choose “Add to Home Screen”.

App installation is provided by your browser and requires a supported browser. The installed app uses an internet connection for live services.

Download KEYCODE Agent

Install the command-line agent on your computer to use KEYCODE from a local project workspace. Node.js is required.
