Admin Access

The KEYCODE admin panel is protected behind multiple security layers. Follow these steps to access it.

1

Start the Admin Server

The admin server runs on port 5001 alongside the main server. It's automatically started when you run node server.js.

2

Open the Admin Portal

Navigate to /admin-panel.html in your browser.

3

Enter Admin Credentials

You'll be prompted for HTTP Basic Auth. Use the ADMIN_BASIC_USER and ADMIN_BASIC_PASS from your .env file.

4

Authenticate

Log in with your admin email and password. The default admin email is keycode.techio@gmail.com.

5

Register a Passkey

For security, register a hardware passkey (Face ID, Touch ID, or security key) to unlock write operations.

⚠
Security Note: The admin server URL is obfuscated and changes on every restart. The path contains 32 random hex characters. Check the server startup logs for the exact URL.
